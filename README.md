# B2BStock

Public-safe case study for a private commercial platform.

**Live site:** [b2bstock.de/en](https://b2bstock.de/en)

## Overview

B2BStock is a B2B liquidation and wholesale pallet auction platform. It combines public auction discovery, authenticated user workflows, admin operations, realtime bidding, payments, invoices, notifications, company verification, inventory management, and mobile access.

## My Role

Designed and developed major full-stack platform workflows across backend APIs, frontend experiences, mobile app behavior, authenticated areas, admin operations, and auction-related modules.

## Platform Modules

- Public auction discovery and auction detail pages
- Realtime bidding and buy-now workflows
- Buyer/user dashboard workflows
- Company verification and onboarding
- Pallet provider and inventory management
- Orders, invoices, and payment-related flows
- Admin panel for users, auctions, bids, content, notifications, and settings
- Multilingual and remote-translation behavior
- Flutter mobile application with Firebase push notifications

## Technology

- Laravel 13, PHP 8.3, REST APIs, Sanctum
- Laravel Reverb/Pusher-style realtime infrastructure
- Stripe payment workflows
- Next.js 16, React 19, TypeScript, Tailwind CSS
- React Query, Radix-style UI components, localization utilities
- Flutter, Dart, Riverpod, GoRouter, Firebase Messaging

## Technical Highlights

- Built auction APIs around pallets, providers, bids, buy-now actions, orders, payments, invoices, and verification.
- Connected public auction browsing to authenticated bidding and purchase flows.
- Added realtime bid updates through backend events and frontend listeners.
- Supported admin operations for pallet inventory, users, verification, content, settings, and notifications.
- Implemented mobile startup behavior with localization fallback and cached/remote translations.

## Privacy

The source code is private. This case study intentionally excludes repository names, credentials, internal URLs, customer/company records, bids, invoices, payment records, provider documents, verification files, and admin screenshots.
